3.2 幻想之境AI 故事共创与长篇写作平台

短篇已上线 长篇完成本地验证 独立产品设计 · AI 协作研发

项目背景：从个人小说创作与短剧灵感需求出发，针对 AI 写作中输入门槛高、续写同质化、前后设定冲突及人物关系难以持续发展的问题，设计以“选择故事世界、与虚拟人物同行、选择后续发展”为核心的网页产品。围绕新手短篇体验、专业创作者长篇共创与快速长篇初稿三类场景，探索从灵感选择、互动写作到章节审查与作品保存的完整流程。独立负责产品定位、需求梳理、交互设计与技术方案，借助 AI 编程工具推进开发和验证。

项目背景 项目职责 项目成果

3.2.1 项目职责

  1. 需求洞察与竞品研究：围绕个人创作中的灵感获取、低输入成本与剧情参与感梳理需求，参考彩云小梦及开源 AI 写作项目，明确每轮提供三段实际故事文字、由用户选择后继续发展的核心机制。结合迭代体验，将产品从小说、热点二创和广告生成收束到故事创作，优先验证人物陪伴与叙事连续性。
  2. 用户分层与创作路径设计：区分创作新手、专业作者与快速初稿用户的控制需求，设计短篇同行、长篇共创和自动初稿三条路径。短篇降低设定与输入门槛；专业模式支持大纲修改、逐章审查和人工采纳；自动模式先确认大纲并试读开篇，再分批推进。两个长篇入口共用作品、章节与修订数据，支持创作方式切换。
  3. 故事内容与虚拟人物设计：梳理日本动漫、欧美影视及中国电视剧的叙事母题，将世界规则、核心矛盾和人物关系转化为原创故事设定。建立二十个故事世界、六十篇精选开局及对应场景配图，为各世界配置具有性格、目标和行为边界的虚拟同行者，提供患难搭档、旧日挚友和亦敌亦友等初始关系。
  4. 提示词设计与上下文管理：将世界规则、人物动机、同行者关系、叙述视角及已选正文组织为生成约束，支持第一人称、第三人称与选填创作要求。明确候选文字只有被用户选中后才成为故事经历，设计带正文引用的同行者记忆，以及撤回最新一段时同步恢复正文、候选与人物状态的规则。
  5. 写作 Workflow 与质量约束：接入 LangGraph 编排生成、结构校验与独立语义审查，参考 Novel-Agent 和自动小说项目，将修订审批、上下文组织、逐章生成和有限返修机制适配到现有网站。区分客观事实、人物信念与人物说法，使用原文片段编号核对审查证据；修改前章或大纲后标记后续内容需要复核，避免沿用失效审查结果。
  6. 成本控制、权限与异常处理：设计访客故事按身份隔离、管理员配置独立保护、调用前费用预留及书级预算上限。梳理生成失败、篇幅异常、任务中断、暂停与重试场景，明确保留可编辑草稿、复用已保存响应、未知结果不自动重试及单步骤有限重试等规则；通过持久化任务状态和租约校验控制重复调用与并发覆盖。
  7. AI 协作研发与验证交付：运用 AGENTS.md、产品约定和项目上下文文档，将需求、实现边界及验收标准转化为 AI 编程任务。推进 React／TypeScript 前端、Node.js 服务端与 Cloudflare D1 数据存储实现，完成腾讯云 EdgeOne 网站部署；分别核对模拟接口测试、真实 DeepSeek 调用和线上访问结果，沉淀部署、迁移、许可证及交接说明，并将源码同步至 GitHub 私有仓库。

3.2.2 项目成果

  • 短篇产品上线与内容体系：完成并上线深色宇宙风格的互动故事网页，首版包含二十个原创世界、六十篇精选开局、二十张场景配图及对应虚拟同行者，支持三候选续写、关系设定、作品保存、文本导出和最新一段撤回，形成可实际体验的创作闭环。
  • 长篇工作台与流程扩展：本地完成专业长篇共创和自动初稿工作台，支持每本 3–60 章、大纲编辑、章节修订、独立审查、人工采纳、批量生成及预算控制。建立共享作品数据与持久化任务机制，提供独立 Node Worker；长篇新版及常驻云 Worker 尚未发布到正式网站。
  • 功能验收与真实模型验证：53 项功能与接口测试、TypeScript 检查及构建通过，覆盖身份隔离、版本校验、证据引用、预算预留、暂停恢复和有限重试。完成真实 DeepSeek 三章流程验证：开篇经人工修改后采纳，第二、三章自动生成、审查并采纳，二十条事实引文均可在对应正文中核对。验证了运行链路与恢复机制，文学质量及长篇阅读体验仍需进一步评测。

当前实现状态：短篇功能已在正式域名提供使用；长篇共创和自动初稿已完成本地实现与验证，尚未更新到正式网站。上述测试结果用于说明功能验证，不代表文学质量或用户增长成果。
